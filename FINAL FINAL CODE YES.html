How to Make Space Invaders in Scratch

Step 1: Setting up the Stage

Start a new project in Scratch and change the stage backdrop to the one called "Stars".

Step 2: The Spaceship/Rocket Sprite

Delete the default Cat sprite, add the Rocketship sprite, and resize it to 35%. Remove its 5th costume. Then add the necessary code blocks to set the backdrop, animate the rocket, and control its movement with the arrow keys.

Step 3: The Invader Sprite

Add the Gobo sprite and resize it to 40%. Then, add the code to position the invader at the top, animate it, and make it move across the screen, dropping down and reversing direction when it hits an edge.

Step 4: Adding a Game Over Screen

Create a new "Game Over" backdrop using the paint tool. Then, add code to the Invader sprite to detect when it touches the rocket. When it does, the game will switch to the "Game Over" backdrop and stop all scripts.

Step 5: Firing a Laser Beam

Paint a new sprite for the laser beam. Then, add the code to make the rocket fire a clone of the laser whenever the space bar is pressed. The clone will start at the rocket's position and move up the screen.

Step 6: Adding a Score

Create a new variable called score. Add a block to reset the score to 0 when the game starts. Finally, add the code to your Invader sprite to check if it's touching the laser, increase the score, and hide.

Step 7: Adding More Invaders

Right-click on your invader sprite and "duplicate" it to create about 10 copies. For each new invader, change its starting X and Y coordinates in the go to x: y: block to create a fleet. Now your game is ready to play!
